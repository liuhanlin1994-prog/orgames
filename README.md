# 千里江山 · 运筹录

水墨风格的运筹学闯关游戏，是「运筹奇境」的重做版。关卡地图是一幅自右向左展开的长卷，参透一处，那一段画卷就从水墨着上青绿，再钤一方印。全部画面和配乐都由代码生成，没有一张图片、一个音频文件。

**直接玩**：用浏览器打开 [`dist/index.html`](dist/index.html)。它是一个完全独立的文件（字体、画面、声音都在里面，不连任何外部网址），断网也能玩。

**发给别人玩**：把 `dist/index.html` 放到任意静态网站托管上，发链接即可。要在国内用微信打开，托管要在国内访问得到：
- 最省事：放到已备案的学校 / 院系网站或个人主页服务器上。
- 自己搭：国内云的静态网站托管（腾讯云 CloudBase、COS，阿里云 OSS 等）。对象存储的默认域名一般不能直接当网页打开，要绑定自己已备案的域名。
- GitHub Pages、Cloudflare Pages、Netlify、Vercel 等海外托管免费又快，但在国内常常打不开，微信里也可能被拦，只适合海外。

- 第一次开卷会先播序章；以后想再看，点右上角「序章」，或在网址后加 `#intro`。
- 开放的关卡都参透后自动播卷终；也可以在网址后加 `#finale` 直接看。

## 十关

| 地点 | 概念 | 玩法 |
|---|---|---|
| 茶寮 | 统筹方法（关键路径） | 一壶茶：按先后点工序 → 三枚「巧」字签：快在哪里才有用，关键路径何时转移 |
| 赛马 | 博弈 · 指派 | 拖动马卡排兵，几场同时开跑：孙膑献策 → 擂台（明牌六匹、限一炷香）→ 暗盘（对手一场一场翻牌） |
| 长亭 | 背包问题（在线取舍） | 亲友一件件递来，每件只等几秒：拖进一格格的书箱、点一下转向，或者留在长亭；箱里的能挪能舍。亲友送行 → 文房四宝（凑齐成套另有加分）→ 书童同行（两只箱子一起算），最后和「事后诸葛」比 |
| 城门 | 排队论 | 实时守门，随时开关城门、可调速：开门迎客（看来客预报赶在人潮前开门）→ 驼队进城（拉一米线）→ 上元灯会（加班工时有限） |
| 客栈 | 收益管理（动态定价） | 灯会前十天实时挂牌，客人看价进门或摇头：平常日子 → 上元灯会（贵客来得晚）→ 账房的算盘（这间房留着值多少） |
| 斗宝 | 拍卖 · 赢者诅咒 | 大相国寺斗宝，凭眼力估价，开标当场鉴定真值，每回合四件：暗标（看得准的少压、看不准的多压）→ 只付次高价（照心里的价出最稳妥） |
| 烽燧 | 选址 · 覆盖 | 点山头修烽火台，望得见的寨子立刻亮起：烽燧（钱只够三座，要望遍十四寨，先修「望得最多」的会顾不全）→ 粮仓（沿山谷拖粮仓，最省在户数过半的中位，不在重心）→ 两仓（路网上修两座，一起想） |
| 断桥 | 最小割 · 最大流 | 江心诸洲由桥相连，点一下桥就拆，敌军够得着的地方立刻染红：断桥（至妙线亮着，找最细的「腰」）→ 运粮（同一张河网拖粮路，运得最多＝拆得最少）→ 江防（更大，有拆不动的石桥，探马回报证明为何不能更省） |
| 马市 | 最优停止 | 亲自相马 → 定规矩，推演一千次 → 一百匹马，找到 37% |
| 七洲洋 | 旅行商 | 凭直觉落笔 → 替老舵工解明结、暗结 → 29 座岛用「就近」「解结」巧解 |

「终卷预览」可以看全卷上色后的样子。

## 沉浸感

- **序章**（约 20 秒）：帷幄中烛光摇曳，算筹一根根落下，摆出「一二 加 二五 得 三七」；天亮时算筹升起、对齐成山脊，晕成水墨远山，再题写书名、钤印。
- **入画与出画**：点「入画」，镜头推近题签，云气合拢，关卡以一张标题页开场（关名、概念、一句古诗文）。
- **长卷上的活物**：帆船往来、炊烟、瀑布、飞鸟，都是代码画的。
- **环境声**：每关有自己的声景：长卷上是风和流水，七洲洋是海浪，城门是市声和驼铃，客栈门前和大相国寺是街市声，赛马场是人群和风，断桥是江水。
- **题跋**：每关结束时，心得一字一字写出来，再钤一方印。
- **卷终**：一个长镜头从引首摇到拖尾，青绿随镜头晕开，诸印依次钤上，最后写下全卷题跋。

## 开发

```bash
npm test            # 52 项模拟测试（Node 22+，无需安装依赖）
npm run build       # 生成 dist/index.html 与 dist/artifact.html
npm run dev         # 在仓库根目录起静态服务，打开 http://localhost:8000/src/ 直接调试源码
```

打包时会检查毛笔字体是否缺字；缺字会自动调用 `build/subset-font.py` 重新子集化（需要 `pip install fonttools brotli`）。

每关结束都有一位「高手」作对照：赛马是精确解，长亭是「事后诸葛」（知道全部物件后的最优装法），城门是「老门官」（按排队论看预报开门、队长加门），客栈是「账房先生」（动态规划算出的最优挂牌价），斗宝是「行家压法」（估价减去六成眼力）与「照心里的价出」，断桥是最大流算出的最省拆法，烽燧是穷举出的最省修法。高手和你面对的是同一批来客；每回合挑的那一天是否典型，也写进了测试。

玩法为什么这样改，见 [`docs/gameplay.md`](docs/gameplay.md)。

## 配乐

D 宫五声调式，64 拍每分钟。笙铺和声、古筝分解和弦与刮奏、箫吹旋律、低音琴弦打底，偶有碰铃。长卷上的曲式为引子 → A → B → A′ → 间奏，循环时重新挑和弦走向和旋律乐句；进入关卡后换成更安静的编排。序章用更空的前奏，卷终用每个和弦都敲钟的终曲。音效都在同一调式里，和配乐不打架。
