# 千里江山 · 运筹录

运筹学闯关游戏「运筹奇境」的重做方案与风格样章。

- [`docs/proposal.md`](docs/proposal.md)：改进 / 重做方案（试玩结论、设计原则、画风、关卡清单、技术方案、路线图，以及原版快修清单）
- [`docs/playtest-notes.md`](docs/playtest-notes.md)：现版本 9 关逐关试玩记录与 bug 清单
- [`prototype/qianli.html`](prototype/qianli.html)：风格样章，单文件，浏览器直接打开即可

## 样章里有什么

- 一幅程序生成的水墨长卷（约七屏宽），自右向左展开，分引首、江南、市井、山川、江海；全卷没有一张图片。
- 11 个关卡题签，点开可看每关的故事、玩法和顿悟设计。
- 可玩关卡「七洲洋」（旅行商问题），三程：凭直觉落笔 → 替老舵工解结 → 群岛巧解。通关后题跋钤印，长卷那一段着上青绿。
- 「终卷预览」按钮可以直接看全卷上色后的样子。
- 琴声由代码合成（Karplus–Strong 拨弦 + 五声音阶），没有音频文件。

标题字体来自 Google Fonts（Ma Shan Zheng、Noto Serif SC），加载不到时回退到系统楷体 / 宋体。
