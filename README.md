# 千里江山 · 运筹录

水墨风格的运筹学闯关游戏，是「运筹奇境」的重做版。关卡地图是一幅自右向左展开的长卷，参透一处，那一段画卷就从水墨着上青绿，再钤一方印。全部画面和配乐都由代码生成，没有一张图片、一个音频文件。

**直接玩**：用浏览器打开 [`dist/index.html`](dist/index.html)。要给学生玩，把这一个文件上传到任意静态托管（Cloudflare Pages、腾讯云 COS 等）即可。

- 第一次开卷会先播序章；以后想再看，点右上角「序章」，或在网址后加 `#intro`。
- 六关都参透后自动播卷终；也可以在网址后加 `#finale` 直接看。

## 现在能玩的六关

| 地点 | 概念 | 三回合 |
|---|---|---|
| 茶寮 | 统筹方法（关键路径） | 一壶茶：按先后点工序 → 三枚「巧」字签：快在哪里才有用，关键路径何时转移 |
| 赛马 | 博弈 · 策略 | 孙膑献策：知道齐王的次序，排兵取胜 → 出马簿：从齐王的习惯里找最好的一手 → 会算的齐王：让他猜不到 |
| 城门 | 排队论 | 开几道门：看一上午的城门口 → 逼近满载：推演百日，看等候怎样陡涨 → 怎么排队：各门各排、一条长队、快者先行 |
| 客栈 | 准入控制（收益管理） | 亲手收一夜的客 → 定下留座的规矩，推演一千夜 → 三种夜晚，先算后验（Littlewood 法则） |
| 马市 | 最优停止 | 亲自相马 → 定规矩，推演一千次 → 一百匹马，找到 37% |
| 七洲洋 | 旅行商 | 凭直觉落笔 → 替老舵工解明结、暗结 → 29 座岛用「就近」「解结」巧解 |

另外五处题签已经在长卷上，点开可以看到每关的故事、玩法和顿悟设计；「终卷预览」可以看全卷上色后的样子。

## 沉浸感

- **序章**（约 20 秒）：帷幄中烛光摇曳，算筹一根根落下，摆出「一二 加 二五 得 三七」；天亮时算筹升起、对齐成山脊，晕成水墨远山，再题写书名、钤印。
- **入画与出画**：点「入画」，镜头推近题签，云气合拢，关卡以一张标题页开场（关名、概念、一句古诗文）。
- **长卷上的活物**：帆船往来、炊烟、瀑布、飞鸟，都是代码画的。
- **环境声**：每关有自己的声景：长卷上是风和流水，七洲洋是海浪，城门是市声和驼铃，客栈是堂中人声和杯盏，赛马场是人群和风。
- **题跋**：每关结束时，心得一字一字写出来，再钤一方印。
- **卷终**：一个长镜头从引首摇到拖尾，青绿随镜头晕开，诸印依次钤上，最后写下全卷题跋。

```

  index.html  style.css  main.js     外壳与入口
  scroll.js                          长卷：构图、分块渲染、拖动、题签、上色、云气飞鸟、入画、卷终长镜头
  core/ink.js                        笔墨引擎：宣纸、干湿笔、山石皴擦、点景、人物、茶具、写意马、印章
  core/prologue.js                   序章动画
  core/audio.js                      配乐、环境声与音效（Web Audio 合成）
  core/chart.js                      推演图（城门、客栈共用）
  core/ui.js  core/rng.js            关卡通用界面、随机数与噪声
  levels/registry.js                 十一处题签的文案
  levels/<关卡>.js / <关卡>-core.js   每关的界面 / 纯逻辑（可在 Node 里测试）
```

## 开发

```bash
npm test            # 31 项模拟测试（Node 22+，无需安装依赖）
npm run build       # 生成 dist/index.html 与 dist/artifact.html
npm run dev         # 在仓库根目录起静态服务，打开 http://localhost:8000/src/ 直接调试源码
```

打包时会检查毛笔字体是否缺字；缺字会自动调用 `build/subset-font.py` 重新子集化（需要 `pip install fonttools brotli`）。

几处「推演」用了同一串随机数来比较不同的方案（城门第一回的同一个上午、客栈第二回的同一千夜），这样方案之间的差别不会被运气盖住；挑的那串随机数是否典型，也写进了测试。

## 配乐

D 宫五声调式，64 拍每分钟。笙铺和声、古筝分解和弦与刮奏、箫吹旋律、低音琴弦打底，偶有碰铃。长卷上的曲式为引子 → A → B → A′ → 间奏，循环时重新挑和弦走向和旋律乐句；进入关卡后换成更安静的编排。序章用更空的前奏，卷终用每个和弦都敲钟的终曲。音效都在同一调式里，和配乐不打架。
